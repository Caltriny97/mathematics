# Declaração e Provas

> [!teorema] Versão operador.
> Para todo operador linear $T: \mathbb{V} \rightarrow \mathbb{V}$ auto-adjunto, num espaço vetorial de dimensão finita munido de produto interno, existe uma base ortonormal $\left\{v_1, \ldots, v_n\right\}$ de $\mathbb{V}$ formada por autovetores de $T$.

> [!teorema] Versão matricial.
> Se $A_{n \times n}$ é uma matriz simétrica, então $A$ é diagonalizável com uma matriz $P$ ortogonal. Isto é, existe uma matriz ortogonal $P$ e uma matriz diagonal $D$ tal que
> 
> $
> A=P D P^{\top} .
> $

Obs. A volta também é válida.
