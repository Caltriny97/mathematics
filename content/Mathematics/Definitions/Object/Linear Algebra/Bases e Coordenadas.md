Quando vamos analisar se um conjunto $\mathcal{B}$ de vetores é uma base do espaço vetorial $\mathcal{V}$, precisamos verificar duas coisas:
* $\mathcal{B}$ é LI?
* $\mathcal{B}$ gera $\mathcal{V}$?
Nessa última, nós tomamos um elemento qualquer de $\mathcal{V}$ e vemos se, para cada elementos de $\mathcal{V}$, existem escalares que satisfaça a equação da combinação linear. Se $\mathcal{B}$ não gerasse $\mathcal{V}$, nós acharíamos restrições para as coordenadas do elementos de $\mathcal{V}$.
