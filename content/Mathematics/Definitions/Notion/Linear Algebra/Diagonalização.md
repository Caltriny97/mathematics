Ver minha nota de aula 21.

Repare que a matriz $P$ é uma matriz mudança de base. Por isso, não podemos montá-la simplesmente colocando as entradas dos autovetores nas colunas de $P$. Assim, estaremos fazendo a conversão da base canônica para a base de autovetores. 

Se for uma base $\mathcal{B}$ genérica, precisaremos calcular a matriz mudança de base, i.e., ver as coordenadas de cada autovetor nessa base e depois fazer o processor inverso para acha $P^{-1}$ ou calcular sua inversa simplesmente.
