> [!teorema]
> Sejam $\left\{u_1, \ldots, u_k\right\}$ vetores não nulos ortogonais de $\mathbb{V}$. Então, para qualquer $v \in \mathbb{V}$, temos que $v-\left(\right.$ proj $_{u_1} v+$ proj $_{u_2} v+\ldots+$ proj $\left._{u_k} v\right)$ é ortogonal a $u_i$, para $i=1, \ldots, k$.

Dado um espaço vetorial e dado um produto interno, conseguimos uma base ortogonal mediante aquele produto interno.

Todo espaço vetorial admite base ortonormal? Sim! Sabemos que todo EV admite base. Assim, basta definir um produto interno e aplicar a ortogonalização de Gram-Schmidt nessa base mediante esse PI. Ao final, temos uma base ortogonal, que podemos normalizá-la para que seja ortonormal.
